TIKTOK LARP SIMULATOR — FIRST VERSION

Files:
- index.html: app UI and interactions
- manifest.json: installable PWA metadata
- sw.js: service worker for app-shell caching
- icon-192.png and icon-512.png: app icons

DEPLOYMENT
1. Upload the contents of this folder to a static hosting provider such as Vercel, Netlify, or GitHub Pages.
2. Make sure the site is served over HTTPS.
3. Open the deployed URL in Chrome (Android) or Safari (iPhone).
4. Android: browser menu > Install app / Add to Home screen.
5. iPhone: Safari Share > Add to Home Screen.

NOTES
- This is an unofficial LARP simulator, not the real TikTok service.
- Follower counts, analytics, rewards, and balances are fictional demo values.
- Profile edits and demo stats are saved locally in the browser.
- Uploaded media is local to the current browser session; there is no cloud upload or real account backend.
- The sample feed images require an internet connection.
